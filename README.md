# IT Support Home Lab

This repository documents my hands-on IT support home lab as I build practical experience with Windows administration, networking, PowerShell, troubleshooting, Active Directory, and related Microsoft technologies.

The goal of the lab is to simulate common tasks and problems that may be encountered in an entry-level IT support environment and document both the configuration process and the troubleshooting methodology used.

## Lab Environment

The initial lab consists of:

- `DC01` — Windows Server 2025 Standard Evaluation
- `CLIENT01` — Windows 11 Enterprise Evaluation
- Oracle VirtualBox
- PowerShell
- Isolated virtual networking

Additional services and systems will be added as the lab develops.

## Repository Structure

### `architecture/`

Diagrams and documentation describing the design and development of the lab environment.

### `networking/`

Networking configuration, testing, notes, and troubleshooting exercises.

### `powershell/`

PowerShell scripts created to inspect, administer, troubleshoot, and automate the lab environment.

### `troubleshooting/`

Documented support incidents containing symptoms, investigation steps, root causes, fixes, and verification.

### `assets/`

Images, screenshots, diagrams, and other supporting files used throughout the documentation.

## Current Status

The lab is currently being built from the ground up.

Initial Windows Server and Windows 11 virtual machines are being configured before networking, Active Directory, DNS, DHCP, Group Policy, and further administration tasks are introduced.

This repository will be updated throughout the project as new technologies, configurations, scripts, and troubleshooting scenarios are completed.

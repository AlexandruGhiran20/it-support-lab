# Troubleshooting

This directory contains documented troubleshooting scenarios performed within the home lab.

Each incident will follow a structured troubleshooting process:

1. Identify the problem
2. Gather information
3. Establish a likely cause
4. Test the theory
5. Implement the fix
6. Verify functionality
7. Document the result

Scenarios will cover Windows, networking, Active Directory, DNS, services, permissions, and other common IT support problems as the lab develops.
